# RetroAchievements coordination notes

## GitHub preview distribution

On 2026-09-23 the owner requested the first Windows and Linux packages on GitHub. `v0.2.1-beta.1` is an experimental pre-release for testing, not formal RetroAchievements client approval, a stable points-earning release, or a submission to the Rekongpiled mod site. This supersedes the earlier private-only distribution plan below; the technical verification and coordination gaps remain open.

On 2026-09-26 the owner completed the final Windows test and requested publication of v0.2.2, with the owner handling the Rekongpiled mod-list submission afterward. Separate platform ZIPs and a combined mod-list ZIP are included. This records the owner's publication decision, not formal RA certification; the remaining technical limits are described in the release notes.

## Earlier testing scope and evidence

The project owner reports that RetroAchievements gave a Discord go-ahead to explore whether a hook-only DK64 Rekongpiled mod can work with the **existing N64 game 10075**. The approach is to use mod callbacks and a native client library, not patch game code or create a separate achievement set. No Discord message text, identity, or formal release approval is archived here, so these notes do not assert any broader authorization.

The new build defaults to **Online** and falls back to **Local Tracking only** without login if the verified DK64 set was previously cached on the PC. A fresh installation with no account and no cache cannot evaluate the full set. No RA condition data is distributed with the mod. The original plan limited sharing to selected testers; the publication decision above supersedes that plan. Online uses the official `rcheevos` award flow after verifying the supported ROM and game 10075; Hardcore and leaderboard submissions remain disabled. The award gate and response parser pass offline tests. A live Online DK Rap trigger returned a server-confirmed softcore unlock for `60497` (0 points), with the colored badge toast and jingle playback request; the browser showed one **Unlocked on RA**. Local trigger IDs are stored per account or Guest profile and ROM and can be reset without touching RA awards or game saves. The earlier local build signed in with a saved token; its browser and badges appeared, DK Rap saved ID `60497` locally, and after a restart the single Reset control's modal Cancel path retained it. This proves one local and one Online trigger path, not the whole set. The server also inserted a zero-point `Warning: Unknown Emulator` entry for this unrecognized client; that warning is not a gameplay unlock. The unique mod user agent should be reviewed/registered rather than impersonating an existing emulator.

For a future public points-earning release, coordinate the concrete client identity, active-ROM verification, memory/trigger equivalence, durable offline award queueing, supported platforms, companion-library packaging, other gameplay mods, Hardcore policy, and evidence from spectator and private Online tests with the appropriate maintainers. Record any release-specific agreement here only with the owner's review. Never include credentials, tokens, ROMs, or private Discord correspondence without permission.
