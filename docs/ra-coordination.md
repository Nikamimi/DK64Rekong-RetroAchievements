# RetroAchievements coordination notes

The project owner reports that RetroAchievements gave a Discord go-ahead to explore whether a hook-only DK64 Rekongpiled mod can work with the **existing N64 game 10075**. The approach is to use mod callbacks and a native client library, not patch game code or create a separate achievement set. No Discord message text, identity, or formal release approval is archived here, so these notes do not assert any broader authorization.

The new build defaults to **Online (softcore beta)** and falls back to **Local Tracking only** without login if the verified DK64 set was previously cached on the PC. A fresh installation with no account and no cache cannot evaluate the full set. No RA condition data is distributed with the mod. The owner intends to share the mod only with selected testers for now, not publish it on the Rekongpiled mod site. Online uses the official `rcheevos` award flow after verifying the supported ROM and game 10075; Hardcore and leaderboard submissions remain disabled. The award gate and response parser pass offline tests. A live Online DK Rap trigger returned a server-confirmed softcore unlock for `60497` (0 points), with the colored badge toast and jingle playback request; the browser showed one **Unlocked on RA**. Local trigger IDs are stored per account or Guest profile and ROM and can be reset without touching RA awards or game saves. The earlier local build signed in with a saved token; its browser and badges appeared, DK Rap saved ID `60497` locally, and after a restart the single Reset control's modal Cancel path retained it. This proves one local and one Online trigger path, not the whole set. The server also inserted a zero-point `Warning: Unknown Emulator` entry for this unrecognized client; that warning is not a gameplay unlock. The unique mod user agent should be reviewed/registered rather than impersonating an existing emulator.

For a future public points-earning release, coordinate the concrete client identity, active-ROM verification, memory/trigger equivalence, durable offline award queueing, supported platforms, companion-library packaging, other gameplay mods, Hardcore policy, and evidence from spectator and private Online tests with the appropriate maintainers. Record any release-specific agreement here only with the owner's review. Never include credentials, tokens, ROMs, or private Discord correspondence without permission.
