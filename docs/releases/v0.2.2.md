# v0.2.2 — badge grid and account controls

Browse achievements in an RA-style badge grid, manage sign-in from **F8 > Account**, and choose whether to remember your login in the Windows sign-in window. This release also includes the trophy thumbnail for the game and Rekongpiled mod list, a smaller Account panel, cleaner labels, and improved Windows ROM-path handling.

Recommended to play with Vanilla DK Rekongpiled. Compatibility with other mods is not guaranteed, but feel free to try.

## Downloads

- **Windows x86-64:** `dk64-ra-windows-x86_64-v0.2.2.zip`.
- **Native Linux x86-64:** `dk64-ra-linux-x86_64-glibc238-v0.2.2.zip`. Linux gameplay and Steam Deck remain unverified.
- **Windows + Linux / mod-list download:** `dk64-ra.zip`, containing the same `.nrm` and both native companions. It also includes `WINDOWS_README.md` and `LINUX_README.md`.
- **SHA256SUMS.txt:** checksums for all three ZIPs. Each ZIP has its own file checksums and `RELEASE_INFO.txt` identifying the source commit.

GitHub's automatic Source code archives are for building the project; install one of the ZIPs above to play.

## Installation

Use **DK64 Rekongpiled 1.0.2** and your own supported US retail ROM. Close the game and back up previous mod files outside `mods/`. Extract the chosen ZIP, then copy **both** `dk64_ra_probe.nrm` and the matching native companion directly into the game's active `mods/` folder:

- Windows: `dk64_ra_probe.dll`. Requires the Microsoft Visual C++ v14 x64 runtime.
- Native Linux: `dk64_ra_probe.so`. This build requires glibc **2.38+**, `GLIBCXX_3.4.30+`, OpenSSL-flavored `libcurl.so.4` (`CURL_OPENSSL_4`), and SDL2. Optional sign-in needs a graphical session with `kdialog` or `zenity`. Do not replace system glibc to run this build.

The combined ZIP works for either platform; install the pair for your game. Windows games under Proton use the Windows DLL. The game's `.nrm` installer alone does not install a native companion. See the included platform guide for portable and standard installation paths. Enable **DK64 RetroAchievements** in Mods and restart after changing achievement mode.

**Online** is the default and submits softcore RA awards. Hardcore and leaderboards are disabled. **Local Tracking only** requires a set cached by a previous successful Online load on that account and PC; a fresh offline installation cannot evaluate achievements. Local triggers are not uploaded later as RA awards.

## Changes

- Replaced the paginated achievement list with a badge grid. Hover or browse with arrow keys, D-pad, or left stick; the detail card shows the selected achievement.
- Added **F8 > Account** for the current RA username, Sign In, and Log Out. Configure points to this panel.
- Moved remembered sign-in into the Windows login window's **Save** checkbox. Only the login token is stored; Linux asks each Online launch.
- Added the supplied trophy artwork as `thumb.png` inside the `.nrm`, plus the vanilla-game compatibility recommendation.
- Removed the old beta labels and redundant Account help paragraphs, and reduced the Account panel height.
- Fixed Windows stored-ROM lookup for standard installations and non-ASCII paths, with separate missing, unreadable, and mismatched-ROM statuses.

## Validation and limits

The owner completed the final Windows test and approved publication on September 26, 2026. Windows offline tests passed **13/13**; Linux offline tests passed **14/14**, including native loading and synthetic SDL input. Linux has build/test validation only; no native Linux game session or Steam Deck validation is claimed.

This is an unofficial RA integration. Earlier Windows testing confirmed the zero-point DK Rap award on RA; full-set accuracy and points-earning parity remain unverified. Authenticated requests can briefly pause the game. Unconfirmed awards have no durable queue across restarts, and stored-ROM checking is not yet bound to the exact bytes selected by the running game. RA may show **Unknown Emulator**.

No game, ROM, achievement definitions, saves, credentials, or local caches are included. Report problems at the [issue tracker](https://github.com/Nikamimi/DK64Rekong-RetroAchievements/issues) with the platform, game version, achievement ID if relevant, and exact error text.
