# v0.2.1-beta.1 — first Windows and Linux testing preview

**Experimental pre-release. Not certified RetroAchievements support.** This is the first downloadable GitHub package, using mod version 0.2.1. No game, ROM, achievement definitions, saves, credentials, or local caches are included.

## Choose your download

- **Windows x86-64:** `dk64-ra-windows-x86_64-v0.2.1-beta.1.zip`. Requires the Windows game and Microsoft Visual C++ v14 x64 runtime.
- **Native Linux x86-64:** `dk64-ra-linux-x86_64-glibc238-v0.2.1-beta.1.zip`. Built on Ubuntu 24.04; requires glibc >= 2.38, `GLIBCXX_3.4.30`, OpenSSL-flavored `libcurl.so.4` (`CURL_OPENSSL_4`), and `libSDL2-2.0.so.0`. Optional sign-in needs a graphical session and `/usr/bin/kdialog` or `/usr/bin/zenity`. **Linux gameplay and Steam Deck are unverified.** Try Deck Desktop mode first. Do not replace system glibc to run this preview.
- **SHA256SUMS.txt:** checksums for both ZIPs. Each ZIP also contains checksums for its files and `RELEASE_INFO.txt` identifying its source commit.

GitHub's automatically generated **Source code** archives are not installable mod packages. Do not use the Linux `.so` with the Windows game under Proton, and do not use these x86-64 companions with an ARM64-native game.

## Install

Use **DK64 Rekongpiled 1.0.2** and your own supported US retail ROM. Close the game and back up any previous mod files outside `mods/`. Extract the chosen ZIP and put **both** `dk64_ra_probe.nrm` and its matching `.dll` (Windows) or `.so` (Linux) directly into the game's `mods/` directory. The game's `.nrm` installer does not install the native companion. Read `TESTER_README.md` for platform-specific paths and requirements.

Enable the mod in Mods, choose the mode before starting gameplay, and restart after changing modes. **Online is the default and submits real softcore awards.** Choose **Local Tracking only** for a no-award smoke test. Local Tracking requires a set cached by a successful Online load on that user account; a fresh offline install cannot evaluate achievements. Local triggers do not later upload automatically.

## Included features

- F8 achievement browser with badges, filters, progress, and account/local status.
- Softcore Online sign-in using the official `rcheevos` client; Hardcore and leaderboards disabled.
- Cached-set Local Tracking and per-profile local progress with a reset confirmation.
- Badge toasts and an original optional achievement jingle.
- Optional remembered login token on Windows; Linux asks each Online launch.

## Validation and known limits

Windows: 10/10 offline tests passed. Earlier limited gameplay confirmed the zero-point DK Rap award on RA, browser/badges, local persistence, and reset Cancel. This does **not** prove the full set or points-earning achievements.

Linux: 12/12 offline tests passed under Ubuntu 24.04/WSL, including native-library loading and synthetic input. Shared-library resolution passed in that build environment. No native Linux game session or Linux account award has been verified.

Authenticated requests can pause a game frame. Unconfirmed awards are not durably queued across restarts. Stored-ROM validation is not yet bound to the exact ROM bytes selected by the running game. Controller behavior, reset Confirm in-game, broader trigger parity, other mods, and Steam Deck require further testing. RA may report **Unknown Emulator**; this client is not claiming formal recognition.

Report issues at the [project issue tracker](https://github.com/Nikamimi/DK64Rekong-RetroAchievements/issues) with platform/distro, game version, mode, achievement ID if relevant, and exact error text. Never upload a ROM, password/token, save, account-private data, or unreviewed game logs.
